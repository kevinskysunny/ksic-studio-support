SmoothCast Support

SmoothCast is a native, local-first tutorial production studio for macOS. Turn one recording into a polished video and a reusable step-by-step guide package: the video, one PNG per step, Markdown, an offline HTML guide, and a JSON manifest.

Contact support
kssicstudio@gmail.com

Include your macOS version, SmoothCast version, steps to reproduce, and screenshots that contain no private information. We normally reply within three business days.

Frequently asked questions

Why can’t SmoothCast record my screen?
Open System Settings → Privacy & Security → Screen Recording, enable SmoothCast, and relaunch the app.
When does SmoothCast use the microphone?
Only recordings for which you explicitly enable microphone narration request and use microphone access.
Does SmoothCast record everything I type?
No. The optional keystroke HUD is disabled by default and runs only during a recording you start after enabling it. It creates local overlay labels for the video and does not upload keystroke data.
Where are my recordings and exports stored?
Recordings and editing metadata stay locally on your Mac. Exports are written only to the location you choose in the macOS save panel.
How do I restore SmoothCast Pro?
Open the Pro upgrade view and choose Restore Purchases while signed in to the same Apple Account used for the purchase.
What is inside a tutorial guide package?
Exporting from the Guide Package editor creates a folder with the tutorial video, one PNG screenshot per step, guide.md, an offline guide.html, and manifest.json. The HTML guide opens in any browser without an internet connection.

SmoothCast 支持

SmoothCast 是一款原生、本地优先的 macOS 教程制作工作室。一次录屏即可同时生成精致视频与可复用的图文教程资料包：视频、每步 PNG 截图、Markdown、离线 HTML 指南与 JSON 清单。

联系支持
kssicstudio@gmail.com

请附上 macOS 版本、SmoothCast 版本、复现步骤，以及不含隐私信息的截图。通常会在 3 个工作日内回复。

常见问题

为什么无法录制屏幕？
请打开“系统设置 → 隐私与安全性 → 屏幕录制”，允许 SmoothCast 访问，然后重新启动 App。
SmoothCast 何时使用麦克风？
仅当你在一次录制中主动开启麦克风旁白时，App 才会请求并使用麦克风权限。
SmoothCast 会记录我的所有输入吗？
不会。按键提示 HUD 默认关闭，仅在你主动启用并开始录制后运行；它只为视频生成本地按键提示，不会上传按键数据。
录制与导出文件保存在哪里？
录制内容和编辑元数据保存在你的 Mac 本地；导出文件仅写入你在 macOS 保存面板中选择的位置。
如何恢复 SmoothCast Pro？
请使用购买时的同一 Apple 账户登录，在 Pro 升级页面选择“恢复购买”。
教程资料包里包含什么？
从教程步骤编辑器导出后，会生成一个文件夹，包含教程视频、每步一张 PNG 截图、guide.md、可离线打开的 guide.html 和 manifest.json。HTML 指南无需联网即可在任何浏览器中打开。
