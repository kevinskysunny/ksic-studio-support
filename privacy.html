KSIC Studio Privacy Policy

Effective date: August 14, 2026

KSIC Studio respects your privacy. This policy explains how the macOS edition of KSIC Studio handles information.

Data we do not collect

KSIC Studio requires no account and contains no advertising, analytics, or tracking SDK. We do not upload your work groups, entries, Recents, or imported files to developer servers.

Local data

The work groups, entries, and Recents you create are stored in the macOS App Sandbox. Resetting the app removes that sandbox data. You can proactively export a backup through the system file picker.

Network access

When you open an entry, KSIC Studio hands its address to your default browser. Only when you manually run a health check does the app directly request the related HTTPS address. The destination website may process information required for that network request according to its own privacy policy. KSIC Studio’s developer does not receive that request data.

File access

Import, export, and restore access only the locations and files you explicitly select through the macOS system file picker.

Changes and contact

We will update this page if the app’s features or data handling changes. For privacy questions, contact kssicstudio@gmail.com.

KSIC Studio 隐私政策

生效日期：2026 年 8 月 14 日

KSIC Studio 尊重你的隐私。本政策说明 macOS 版 KSIC Studio 如何处理信息。

我们不收集的数据

KSIC Studio 不要求注册账户，不包含广告、分析或跟踪 SDK，也不会向开发者服务器上传你的分组、入口、最近使用记录或导入文件。

本地数据

你创建的分组、入口和最近使用记录保存在 macOS App Sandbox 中。重置 App 会删除这些沙盒内数据。你也可以通过系统文件选择器主动导出备份。

网络访问

打开入口时，KSIC Studio 将地址交给系统默认浏览器。只有在你主动执行健康检查时，App 才会直接请求对应的 HTTPS 地址；目标网站可能按其自身隐私政策处理网络请求所必需的信息。KSIC Studio 开发者不会接收这些请求数据。

文件访问

导入、导出与恢复仅访问你通过 macOS 系统文件选择器明确选取的位置和文件。

政策变更与联系

如功能或数据处理方式发生变化，本页面会同步更新。如有隐私问题，请联系 kssicstudio@gmail.com。
