PresenterDeck Privacy Policy

Effective date: August 25, 2026

PresenterDeck is a 100% offline macOS presentation utility. This policy explains how the App handles information. In short: we do not collect, track, store, transmit, or monetize any personal data, keystrokes, or screen contents.

1. Zero data collection

PresenterDeck collects no personal data or usage metrics:

No user accounts or sign-up. No keystroke logging: the Keystroke HUD renders key labels in memory on screen and discards them immediately. No screen recordings are stored: annotations and overlays are drawn on your display in real time and never saved or transmitted. No analytics or ads: zero telemetry, zero analytics SDKs, and zero third-party trackers.

2. macOS system permissions

PresenterDeck requests the minimum permissions needed to deliver its presentation features:

Accessibility, to capture global shortcut keys (for example Option+D, Option+S) while presenting over third-party applications. Input Monitoring, used only by the Keystroke Visualizer to display pressed key combos for tutorial viewers. All permission handling stays local to your Mac under the macOS App Sandbox.

3. Network and cloud policy

PresenterDeck makes zero outbound network requests. It operates entirely offline and has no backend server or cloud dependency.

4. Children's privacy

Because PresenterDeck collects no personal information, it complies fully with COPPA and similar regulations worldwide.

5. Changes to this policy

If PresenterDeck's features or data handling change, this page will be updated accordingly.

6. Contact

For privacy questions, contact support@presenterdeck.app.

PresenterDeck 隐私政策

生效日期：2026 年 8 月 25 日

PresenterDeck 是一款 100% 离线运行的 macOS 演示辅助工具。本政策说明 App 如何处理信息。简而言之：我们不收集、不追踪、不存储、不上传也不会利用你的任何个人数据、按键内容或屏幕内容。

1. 零数据收集

PresenterDeck 不收集任何个人数据或使用指标：

无需注册账号或登录。不记录按键：按键提示浮层仅在内存中渲染按键标签并立即丢弃。不保存屏幕录制内容：标注与悬浮层实时绘制在你的屏幕上，从不保存或上传。无广告、无统计：零遥测、零统计 SDK、零第三方跟踪。

2. macOS 系统权限

PresenterDeck 仅申请实现演示功能所需的最小权限：

辅助功能权限，用于在其他应用之上演示时捕获全局快捷键（例如 Option+D、Option+S）。输入监控权限，仅由按键提示器在演示教学时显示按下的组合键。所有权限处理都在 macOS App 沙盒内本机完成。

3. 网络与云策略

PresenterDeck 不会发起任何对外网络请求。它完全离线运行，没有后端服务器或云依赖。

4. 儿童隐私

由于 PresenterDeck 不收集任何个人信息，因此完全符合 COPPA 及全球相关法规。

5. 政策变更

如 PresenterDeck 的功能或数据处理方式发生变化，本页面会同步更新。

6. 联系我们

如有隐私问题，请联系 support@presenterdeck.app。
