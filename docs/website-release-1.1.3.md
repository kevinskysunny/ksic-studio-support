# 支持站 1.1.3 · 2026-09-05

美区网页在开发者当前中国网络环境仍跳到 /cn/iphone/today。1.1.2 的链接策略不足以解决这一问题；美国区网页不再作为唯一首选商店入口。

首页及三款产品的中英文页面新增不含地区代码的 macappstores://apps.apple.com/app/id…?mt=12 原生入口。保留中国区和美国区网页预览，明确网页重定向问题及账户地区/当地上架限制。不按语言猜测商店地区，不采集 IP 或定位，不自动打开外部应用。推广应分享本站产品页，让访客自主选择入口。

验证证据：本机 App Store.app 的 CFBundleURLSchemes 包含 macappstores。通过中国区 Apple 官方 NetworkConsole Lite 产品页点击“在 Mac App Store 中查看”，原生 App Store 成功显示对应产品。自定义无地区原生 URL 的直接浏览器测试被工具 URL 安全策略拒绝，因此未验证该 URL 的端到端行为，不能宣称全球访问已通过；没有绕过策略。海外实际网络与账户仍待验证。三款应用美国区正式记录已于前一版本查证。

静态校验覆盖三个产品 ID、中英文原生与网页入口、版本一致性。未更改商店账户、销售地区或应用版本。
