Frequently asked questions

Where is my data stored?
Work groups, entries, and Recents stay in the App Sandbox and are not uploaded automatically.

Why does an HTTP address have no health status?
For connection safety, the app checks HTTPS addresses only. HTTP addresses can still open in your default browser.

How do I migrate configuration?
In Settings, import a web-edition JSON file or use the store edition’s backup and restore features. Back up before importing.

How does language selection work?
The app follows the language selected for it in macOS and supports English and Simplified Chinese. Change the app language in macOS settings, then relaunch the app. There is no separate in-app language setting.

How do I remove all data?
Use Restore Default Entries in Settings. Export any configuration you want to keep first.

常见问题

数据保存在哪里？
分组、入口和最近使用记录保存在 App Sandbox，不会自动上传。

为什么 HTTP 地址没有健康状态？
为保护连接安全，App 仅检查 HTTPS 地址；HTTP 地址仍可交给系统默认浏览器打开。

如何迁移配置？
在“设置”中选择导入 Web 版 JSON，或使用商店版的导出与恢复功能。导入前建议先备份。

语言如何切换？
App 自动跟随 macOS 为此 App 选定的语言，支持简体中文和英文。请在 macOS 设置中更改 App 语言后重启 App；App 内无需额外的语言设置。

如何删除全部数据？
在“设置”中使用恢复默认入口。执行前请导出需要保留的配置。
