NetworkConsole Lite support

Read-only network checks for macOS 14.0 or later.

Get started

  1. Open the app from Applications or its menu bar icon.
  2. Run a check and open the details window to inspect interfaces, DNS, routes and internet connectivity.
  3. Read the suggested next steps. The app does not change your network settings or automatically fix your connection.

Sharing a support package

Export a redacted support package only when needed. Review the file before sharing: network details can still be sensitive. Exporting saves a file locally; it does not send it to support.

Contact

Email kevinskysunny@gmail.com with your macOS and app versions and reproduction steps. Remove private network addresses, passwords and other sensitive information from screenshots.

App privacy policy · Product information

NetworkConsole Lite 支持

适用于 macOS 14.0 或以上版本的只读网络体检。

开始使用

  1. 从“应用程序”或菜单栏图标打开应用。
  2. 运行检查，在详情窗口查看接口、DNS、路由与互联网连通性。
  3. 阅读下一步建议。应用不会修改网络设置，也不会自动修复连接。

分享支持包

仅在需要时导出脱敏支持包，发送前仍需检查文件，网络细节可能包含敏感信息。导出只会保存本地文件，不会发送给支持人员。

联系支持

请向 kevinskysunny@gmail.com 提供 macOS 与应用版本、复现步骤。请从截图移除内网地址、密码及其他敏感信息。
